Dessins et versions — six façons

Trois dessins occupent le même emplacement: le plan d'étage du bureau, le plan de l'arpenteur, le plan du paysagiste. Il faut pouvoir n'en lire qu'un, les empiler avec une opacité par dessin, et savoir d'un coup d'œil si celui qu'on lit est le dernier reçu.

Chaque option est dessinée dans l'écran où elle vivrait, avec les vraies planches. Les commandes sont actives: œil, opacité, isolement, import d'une version, historique. Dans l'option 6, la version précédente est figurée par une autre planche, faute d'archive réelle.
