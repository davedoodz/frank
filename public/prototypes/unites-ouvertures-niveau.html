Unités & ouvertures — les unités écrites une seule fois

Sur un étage, le volet liste aujourd'hui les quinze unités deux fois : une table des superficies, puis une table des ouvertures. Six façons de dire les deux avec une seule liste d'unités. Mêmes chiffres partout (niveau 5). Un clic sur une unité la sélectionne dans les six.
