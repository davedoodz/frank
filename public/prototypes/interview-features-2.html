Prototype 02 · User testing · Wednesday, October 28

What Benoît and Guy noticed

The second test focused on the coordination workspace already on screen. These notes preserve what each technician found unclear, what information was missing, and which parts of the drawing workflow need refinement.

Benoît · 2D specialist Guy · 3D specialist Cross-interview finding
Central insight

Both technicians focused on usability and workflow details rather than asking for entirely new features. The prototype’s value depends on making existing architectural tasks faster, clearer and easier to navigate.

  • ControlsMake actions discoverable and explain unfamiliar interactions.
  • CalculationsShow practical totals and breakdowns architects use.
  • DrawingsImprove zoom, resizing, opacity and version history.
  • TerminologyUse familiar architectural language.
  • RegulationsMake codes and municipal workflows easier to retrieve.
  • TrackingClarify comments, priorities and calendar information.

Navigation and discoverability

Make controls explain themselves

Benoît
  • Closing pop-up bubbles with the × is not obvious.
  • Add tutorials or contextual hints for new users.
  • The error button hides the problem instead of making it visible.

Make the drawing viewport easier to control

Benoît
  • The mouse-wheel direction for zooming into floor plans feels inverted.
  • Allow users to resize the viewing panels.
  • Increase the maximum zoom level.

Use language the office already uses

Guy
  • The commenting system is unclear.
  • The term Distribution is not intuitive.
  • Avoid technical file terminology such as .csv, which users may not understand.

Drawing navigation and versions

Make previous drawing versions usable

Guy
  • Fix the functionality for viewing previous drawing versions.

Clarify opacity and start from the drawing

Guy
  • Opacity controls are unclear.
  • Set drawing opacity to 100% by default.

Calculations and documentation

Show the unit mix and the project total

Benoît
  • Show the percentage breakdown of unit types: 3½, 4½ and 5½.
  • Display the total net area across all units in square feet.

Make quantities practical, not merely complete

Benoît
  • Total material quantities are less useful than material quantities per façade.
  • Investigate why window quantities display decimals such as 0.3.

Find a unit or article, then export what is useful

Benoît
  • Add a smart search bar that opens a specific unit or retrieves the relevant building-code articles.
  • Allow users to export data tables as PDFs.

Codes and municipal workflow

Organize regulations around how they are reviewed

Guy
  • Organize building codes in chronological order.
  • In Codes & Regulations, replace Client with Municipalité / Ville where appropriate.

Keep municipal referrals visible

Guy
  • Account for referrals between municipal departments, particularly to the Director of Urban Planning Services.

Project tracking

Use comments as the project’s shared unit of follow-up

Benoît
  • Replace Tâche with Commentaire in the Échéancier interface.

Make the calendar lead back to the project

Guy
  • Clicking a calendar date should display the corresponding project information.

Reserve green for progress, not urgency

Guy
  • Use red and orange for priority indicators rather than green.
